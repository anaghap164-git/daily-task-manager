# Daily Task Manager

A web-based Daily Task Management application designed to organize, assign, monitor and track daily tasks.

## Features
- Dashboard overview
- My Tasks
- Completed Tasks
- Pending Tasks
- Application Settings
- Add New Task
- Task priority and status tracking
- Task due-date monitoring
- Responsive interface

## Technologies
- HTML5
- Tailwind CSS
- JavaScript

## Project Purpose
To simplify daily task management through a centralized dashboard with task tracking and monitoring capabilities.
